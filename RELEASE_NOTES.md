# Notes de la prochaine version

Écrire sous la ligne `<!-- notes -->` les changements de la prochaine version, en Markdown (une
ligne `- …` par changement). À chaque push sur `main`, la CI publie ce texte comme description de
la GitHub Release, puis vide la liste dans le commit `Version X.Y.Z`. Sans notes, GitHub génère la
liste des commits. Détails : [docs/release.md](docs/release.md).

<!-- notes -->
- Le halo du micro est plus grand et reste visible autour du doigt pendant la dictée.
- La dictée recoupe localement les quantités manquantes pour éviter de confondre « deux » avec « de ».
- La dictée distingue mieux les quantités successives, les nombres composés et les décimales.
- Le micro reste en place et grossit avec un halo animé pendant la dictée.
- Dictez vos courses en maintenant le bouton microphone, puis corrigez le récapitulatif avant de les ajouter.
- La dictée fonctionne hors ligne grâce à un moteur vocal embarqué dans les six langues, sans services Google.
